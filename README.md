##**<ins>Description</ins>**

This program asks the user for their age and returns the age group. If the person is between 0 and 12 years old, the program returns "Child". If the person is between 13 and 17 years old, the program returns "Teen". If the person is between 18 and 64 years old, the program returns "Adult". And finally, if the person is between 65 and 105 years old, the program returns "Senior". If the number is anything else, the program returns "Invalid age input".

I asked the user for their age as and integer using an input function. I then used if and elif statements to provide the conditions for which to print the age group. Then, in case of any negative number, floats, or non-numeric inputs, I had an else statement to print "Invalid age input".
